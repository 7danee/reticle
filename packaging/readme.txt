reticle – Crosshair-Overlay für Windows
=======================================

Ein eigenes Fadenkreuz über jedem Spiel. Kein Installer, eine einzige Datei.
Projektseite und Updates: https://github.com/7danee/reticle


SO GEHT'S
---------

1. Den Ordner "reticle" irgendwohin entpacken, zum Beispiel nach
   Dokumente\reticle. Nicht direkt aus der Zip starten.

2. reticle.exe doppelklicken.

   Windows zeigt beim ersten Mal "Der Computer wurde durch Windows geschützt".
   Das liegt nur daran, dass die Datei nicht signiert ist. So geht es weiter:
   "Weitere Informationen" -> "Trotzdem ausführen".

3. Das Crosshair erscheint in der Bildschirmmitte. Unten rechts im
   Infobereich (ggf. über den kleinen Pfeil) sitzt das Symbol "r.".
     - Linksklick: Einstellungen öffnen
     - Rechtsklick: Menü (anzeigen, Stream-Schutz, Beenden)
     - F8: Crosshair ein- und ausblenden

4. Im Spiel den Anzeigemodus auf "Randloses Fenster" / "Borderless" /
   "Vollbild (Fenster)" stellen. Über echtem Vollbild ("Exklusiv")
   ist das Overlay nicht sichtbar.


TIPPS
-----

- Crosshair-Code von Freunden: Einstellungen -> Presets -> "Code einfügen".
  Funktioniert auch mit Codes aus CS2 und Valorant.
- Eigenes Crosshair teilen: Presets -> "Code kopieren" und in Discord einfügen.
- Pro Spiel ein anderes Crosshair: Reiter "Profil" -> "Neues Profil".
  Bei ROB RUN das Spiel einmal starten und unter "Laufende Programme" wählen.
- Mit Windows starten: Reiter "Optionen" -> "Autostart".
- Alles wird hier gespeichert: %APPDATA%\reticle


WICHTIG
-------

reticle legt nur ein durchsichtiges Fenster über den Bildschirm. Es liest
keinen Spielspeicher, verändert keine Spieldateien und wertet den Bildschirm
nicht aus. Trotzdem gibt kein Spielehersteller eine offizielle Freigabe für
Crosshair-Overlays. Nutzung auf eigenes Risiko, besonders in Ranglisten,
Turnieren und Ligen.


ENTFERNEN
---------

Über das Tray-Menü "Beenden", dann den Ordner löschen. Falls Autostart an war,
vorher in den Optionen ausschalten. Einstellungen liegen in %APPDATA%\reticle.
