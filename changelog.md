# Changelog

## v0.5.0 – erste Veröffentlichung

### Overlay
- Crosshair pixelgenau in der Bildschirmmitte, klickdurchlässig, immer im Vordergrund. Das Spiel wird nicht angefasst.
- **F8** blendet ein und aus, Tray-Symbol „r.“ (grüner Punkt = an, grau = aus).
- Monitor **Automatisch**: folgt dem Monitor des Spiels; fester Monitor wählbar.
- **Im Stream verstecken**: unsichtbar für OBS, Discord-Stream und Screenshots.
- **Mit Windows starten** (optional).
- Komplett ereignisgesteuert: im Leerlauf 0 % CPU, unter 2 MB Speicher.

### Crosshair
- Ebenen: Kreuz, Punkt, Kreis, Chevron und eigene Bilder (PNG/SVG), beliebig kombinierbar.
- Farbe mit Deckkraft, Dicke, Länge (auch getrennt waagerecht/senkrecht), Abstand, T-Form, Kontur.
- 7 mitgelieferte Presets, eigene Presets speichern.

### Profile
- Eigenes Crosshair, Versatz und Zielverhalten je Spiel; Wechsel automatisch, wenn das Spiel nach vorn kommt.
- Vorlagen für Counter-Strike 2, Valorant, PUBG, GTA V, FiveM und ROB RUN.
- **Beim Zielen** (rechte Maustaste): ausblenden solange gehalten oder ein/aus je Klick.
- Optional: nur in Spielen mit Profil anzeigen.

### Teilen
- Code kopieren und einfügen (`rtcl1:…`) – ohne Server, z. B. über Discord.
- Import von Counter-Strike-Codes (CS2 `CS…` und alte `CSGO-…`) und Valorant-Codes, umgerechnet auf deine Bildschirmhöhe.
- Export als PNG.

### Einstellungsfenster
- Schmal und minimal, Dunkel/Hell, Live-Vorschau mit Zoom. Jede Änderung ist sofort im Spiel sichtbar.
- Eigener Prozess: nach dem Schließen belegt es keinen Speicher mehr.
